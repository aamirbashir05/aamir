Gemini AI Enhance — Setup

Ek baar ka setup (~10 min). Iske baad tool background hatne ke baad photo ko Gemini AI se HD studio-quality bana dega.

100% FREE · koi credit card nahi · ~500 image/din

1 Free Gemini API key lein

Google AI Studio kholein aur "Create API key" dabayein. Jo key mile, use copy kar lein (secret rakhein).

🔑 API key banayein →

2 Cloudflare (free) par Worker banayein

Free Cloudflare account banayein → Workers & Pages → Create → Worker → koi bhi naam do → Deploy.

☁️ Cloudflare Worker →

3 Ye code paste karein

Worker khulne par "Edit code" dabayein, jo pehle se likha hai wo sab hata dein, aur ye poora code paste kar ke Deploy karein.

Loading…

Code load na ho to yahan se copy kar lein.

4 Apni key Worker me daalein

Worker ke Settings → Variables and Secrets me jaayein → Add → naam bilkul GEMINI_API_KEY rakhein → value me apni Step-1 wali key paste karein → Save / Deploy.

5 Worker ka URL copy karein

Worker ke page par uska URL milega (jaise https://naam.aapka-account.workers.dev). Use copy karein.

✓ Aakhri step — URL yahan paste karein

Worker URL neeche daal ke Save dabayein — tool me Gemini enhance chalu ho jayega (is browser me save ho jayega).

✓ Save ho gaya! Ab tool me jaa kar photo enhance karein.
